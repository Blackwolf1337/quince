# Security policy

## Supported versions

Only the latest release gets fixes.

| Version | Supported |
|---|---|
| 0.3.x | yes |
| older | no |

## Reporting a problem

Send a private message on Discord to the user `xleuiv`. Do not use a public issue or pull request.

Please include:

- the Quince version and the system (Linux, Windows or macOS)
- the steps to reproduce it
- what an attacker can do with it
- a proof of concept, if you have one

## What happens next

I will acknowledge the report, fix the problem in a new release and credit you if you want. I cannot promise time frames.

## What counts

Quince stores the YouTube session cookies on your computer (see [docs/usage.md](docs/usage.md) for the files). A problem that leaks them, or that lets another program or site read them, is a security issue.
